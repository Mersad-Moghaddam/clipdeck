## Draft description (not submitted)

ClipDeck is a keyboard-first clipboard daemon and CLI for compatible Wayland
sessions, with persistent searchable history, typed previews, pins, transforms
and privacy controls. An Omarchy-specific Quickshell plugin provides the rich
overlay. The development branch adds a portable copy-first menu command and
server-side category paging. Desktop capabilities vary: consult the tested
compatibility matrix rather than assume universal monitoring/paste support.
